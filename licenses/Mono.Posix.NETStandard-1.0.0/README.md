# Mono.Posix.NETStandard 1.0.0 licensing

Resolved transitively from LibreHardwareMonitorLib 0.9.6 for the win-x64 helper.
The package contains the managed assembly and the native `MonoPosixHelper` libraries.

The NuGet 1.0.0 metadata does not declare an SPDX expression. Its official legacy
license URL is https://go.microsoft.com/fwlink/?linkid=869050, which resolved on
2026-11-02 to https://github.com/mono/mono/blob/main/LICENSE.

`LICENSE` and `PATENTS.TXT` are preserved from those official Mono sources. Because
the referenced file is a composite Mono distribution license rather than a
component-specific SPDX declaration, applicability to the exact 1.0.0 managed and
native files should be reviewed before commercial distribution.
